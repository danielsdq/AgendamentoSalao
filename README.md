# ✂️ Agendamento Salão


O **Agendamento Salão** é uma aplicação desenvolvida para modernizar e facilitar a gestão de horários em salões de beleza, barbearias ou clínicas de estética. A plataforma permite que clientes agendem serviços de forma online e que os administradores gerenciem o fluxo de atendimento com eficiência.

---

## 🚀 Funcionalidades

* **Para os Clientes:**
    * Cadastro e login de usuários.
    * Visualização de serviços disponíveis e profissionais.
    * Escolha de data e horário com base na disponibilidade em tempo real.
    * Histórico de agendamentos realizados.

* **Para os Administradores/Profissionais:**
    * Painel de controle (Dashboard) para visualização dos agendamentos do dia.
    * Gestão de serviços (criar, editar, excluir).
    * Controle de horários e bloqueio de agendas.

---

## 🛠️ Tecnologias Utilizadas



* **Backend:** [Java Spring Boot]
* **Banco de Dados:** [ MongoDB]
